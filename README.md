# Sistema de Gerenciamento de Barbearia

Projeto da disciplina de Engenharia de Requisitos.

## Estrutura

```
barbearia/
├── docs/            # Documentação do projeto
│   ├── requisitos/  # Requisitos funcionais, não funcionais, regras de negócio
│   ├── diagramas/   # Casos de uso, classes, sequência, ER
│   └── prototipos/  # Wireframes e protótipos de tela
├── backend/         # API e regras de negócio
│   ├── src/
│   └── tests/
├── frontend/        # Interface do usuário
│   ├── src/
│   ├── public/
│   └── tests/
└── database/        # Scripts, migrations e seeds
```
